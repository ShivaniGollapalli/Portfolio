# Shivani Gollapalli — Portfolio

A modern, responsive personal portfolio website showcasing my experience, skills, projects, and professional background as a Full Stack Developer.

The portfolio is designed with a clean, minimal dark UI and focuses on presenting technical work, professional experience, and development capabilities in a simple and professional way.
